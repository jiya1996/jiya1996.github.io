# joker 三端前端验收 · FE-20261101-01

打开 https://jiya1996.github.io/rzh/mvp/ 。下载本目录后可通过 `python3 -m http.server 8891` 在本机预览。

玩家、荷官、直播播报屏及倒计时屏沿用各端最新交互稿，统一身份映射、八套预览配色、入座开局、计时播报和正式前三展示。点击导航页“准备三位测试玩家”后，按页面步骤验收。原 joker/ 客户链接保持原样。

本包是同一浏览器、同一来源的多标签前端演示，不提供跨设备共享、正式认证、真实收银或发奖。数据使用独立存储空间。新增注册从0次开始；主动准备的三位虚构测试玩家各3次，重复准备不重复发放。次数和门票分开，新赛果不套用旧统计自动授勋。

声音首次需在播放设备点击启用；静态包使用设备朗读与程序音效，失败保留异常供人工补播。“仅画面预览”不代表语音播出。物理电视／手机、外接音响、Safari、正式后端和数据库未由本次演示验收替代。

本轮47项既有玩家测试、44项三端浏览器联测及2项音画／320像素专项通过。浏览器取得四条朗读开始和结束事件，AudioContext运行，完成状态回写；物理扬声器未验。具体检查见 validation/。

原始四端侧文件的SHA-256定位见 version.json；当前静态文件清单见 build-manifest.json。源码即本目录HTML、共享适配JS及CSS。最终商家后台在本次前端验收后，按各端反推的配置、权限和纠错需求另行确认设计。
